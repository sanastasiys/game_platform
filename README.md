# WEB QUEST — Бесконечная сессия

Браузерный платформер о студенте, который проходит курс WEB-дизайна, собирает практические задания и сдаёт семестры преподавателю Кокорину Евгению Сергеевичу. Интерфейс вдохновлён визуальным стилем учебного портала: тёмные карточки, крупная типографика, лаймовые/коралловые акценты. **Это самостоятельный учебный проект, не официальный продукт портала.**

## Запуск

### Самый простой

Откройте `play.html` двойным щелчком в современном Chrome/Firefox/Safari. В нём HTML, CSS и JavaScript собраны в одном файле, поэтому сервер не нужен.

### Исходники (ES-модули)

Запустите из папки проекта простой локальный сервер:

```bash
python3 -m http.server 8000
```

Перейдите на `http://localhost:8000` и откройте `index.html`.

Готовых игровых движков, npm, сборщиков и сторонних картинок нет. JavaScript ванильный; рисунки создаются средствами Canvas.

## Как играть

**Управление:** `←` / `→` или `A` / `D` — движение; `Пробел` / `W` / `↑` — прыжок; `Esc` — пауза. На телефоне есть экранные кнопки, удержание работает через Pointer Events. Второй прыжок в воздухе недоступен.

Перед началом выберите одного из шести вымышленных студентов. У каждого собственная история и игровой бонус:

| Персонаж | История | Особенность |
|---|---|---|
| Кирилл Королёв | Хронический троечник, сдаёт за минуту до дедлайна | +30% очков за практики |
| Полина Белова | Эксперт по расписанию пересдач | 1 щит в начале каждого уровня |
| Артём Орлов | Восстановился после отчисления | 1 возвращение к последней собранной контрольной |
| Виктория Смирнова | Староста потока | +50 очков за каждый бонус |
| Данила Волков | Остался на второй год | Прыжок на 7% выше |
| Мария Ким | Легенда общежития | Кофе действует в два раза дольше |

Собирайте книжки-практики и звёзды контрольных, затем дойдите до преподавателя. Количество работ зависит от номера уровня и растёт до 16.

| Доля собранных работ | Итог |
|---|---|
| 100% | 5 — отлично |
| от 80%, но меньше 100% | 4 — хорошо |
| от 60% до 79% | 3 — зачёт, следующий уровень |
| от 40% до 59% | 2 — пересдача |
| меньше 40% | 1 — пересдача |

При столкновении с опасностью без щита/спасения уровень завершается поражением. При повторе счёт *пройденных* уровней и очки забега остаются; очки, собранные в неудачной попытке, не прибавляются. Рекорд уровня, рекорд очков и выбранный студент хранятся в `localStorage` с обработкой ошибок хранения. При доступности старого рекорда версии v2 новый проект подхватывает его при первом запуске.

## Как растёт сложность

- **Уровень 1:** знакомство с прыжками и предметами.
- **Уровень 2:** платформы начинают двигаться влево-вправо.
- **Уровень 3:** вертикальные платформы и летающий враг «Сессия».
- **Уровень 4:** движущиеся колючки и наземные патрули.
- **Уровень 6:** платформы, которые разрушаются после 0,88 с стояния на них.
- **Каждый 5-й уровень:** мини-босс — увеличенная летающая «Сессия» возле последней части маршрута.
- **Далее:** больше платформ, работ, пролетающих сессий и совмещённых ловушек. Скорости и геометрия ограничены, чтобы сложность не уходила в физически невозможные прыжки.

Бонусы: **кофе** — на 6 секунд замедляет опасности (у Марии на 12); **автосохранение** — выдаёт щит от одного столкновения с врагом/колючками (от падения щит не спасает) (максимум два одновременно); **стипендия** — очки. Предметы собираются один раз. Серии быстрых сборов дают комбо-очки, а пятёрки и быстрая сдача увеличивают итоговый результат.

В 1500 процедурно сгенерированных уровнях проверены ограничения ширины платформ и разрывов. Это **проверка параметров генератора**, а не доказательство прохождения каждого уровня человеком; желательно дополнительно сыграть в сложные уровни перед сдачей.

## Файлы

- `index.html` — страница и разметка игры;
- `style.css` — адаптивный интерфейс;
- `main.js` — управление кнопками и отображение результатов;
- `Characters.js` — шесть персонажей, биографии, способности, рисование;
- `Game.js` — цикл, состояние, Canvas, оценка, эффекты и враги;
- `Level.js` — процедурная генерация;
- `Player.js` — движение, прыжок, перенос движущейся платформой;
- `collision.js` — столкновения сверху, снизу и сбоку;
- `input.js` — клавиатура и мобильные кнопки;
- `play.html` — собранная офлайн-версия из исходников.

`play.html` — готовая одностраничная версия для запуска без сервера. Для GitHub Pages используется `index.html` и отдельные ES-модули. Сборка, npm и игровые движки не требуются.

## Что проверить вручную

1. Выберите другого персонажа и убедитесь, что игра использует именно его внешний вид и умение.
2. Убедитесь, что в воздухе нельзя совершить второй прыжок.
3. На уровне 2 встаньте на горизонтальную платформу — она должна переносить героя; на уровне 3 проверьте вертикальную.
4. На уровне 4 обойдите движущиеся колючки и летающую Сессию; на уровне 6 проверьте разваливающуюся платформу.
5. Соберите все предметы и получите 5; соберите 60–79% и получите 3; меньше 60% — пересдача.
6. Проверьте кофе, щит, падение, пять рестартов подряд, паузу и уход со вкладки.
7. Обновите страницу, чтобы проверить сохранённый рекорд; проверьте управление на телефоне.

## Публикация

1. Создайте публичный репозиторий на GitHub и загрузите файлы из архива.
2. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
3. Дождитесь появления адреса вида `https://USERNAME.github.io/REPO/`.
4. В отчёт добавьте ссылку на игру, репозиторий и скриншоты прохождения.

## Использованные материалы

Все студенты — вымышленные персонажи, а их портреты нарисованы кодом. В игре используются только фигуры Canvas, CSS и стандартные системные шрифты: внешние изображения, звуковые файлы и лицензируемые ассеты не требуются. Ссылка на учебный портал дана как источник визуального вдохновения, код или графика портала в проект не копировались. Звука нет.

## Обновление внешности персонажей (v5)

После замечания о «бороде» у Полины спрайты были переработаны послойно: задняя часть волос рисуется **за корпусом**, затем шея/лицо, а поверх лица — только чёлка. Полина теперь носит высокий хвост с резинкой, Виктория — пучок, Мария — каре с заколкой. Для портретов выбран масштаб, при котором верх причёски не обрезается. Эти же рисунки используются непосредственно в игре. Обычные механики, управление и прогресс остались прежними.

После загрузки на GitHub проверьте выбор персонажа, перезапуск, поражение и сохранение рекорда.


## Быстрая публикация на GitHub Pages

1. Создайте **публичный** репозиторий, например `web-quest`.
2. Перенесите **содержимое этой папки** в корень репозитория. Не загружайте ZIP как один файл: его сначала нужно распаковать.
3. Убедитесь, что `index.html`, `style.css` и `.js`-файлы находятся на одном уровне.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Адрес игры будет иметь вид `https://ВАШ-ЛОГИН.github.io/web-quest/`. Проверьте его после публикации.

Для сдачи отправьте две ссылки: на игру и на репозиторий.
